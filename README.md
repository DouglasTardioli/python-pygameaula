# 🎮 Projeto Pygame — Aula de Python

Projeto desenvolvido em **Python utilizando a biblioteca Pygame**, com o objetivo de praticar conceitos de programação e desenvolvimento de jogos 2D.

Este projeto faz parte dos meus estudos em **Python e desenvolvimento de jogos**, explorando recursos como criação de janelas, gráficos, imagens, fontes, sons, eventos e interação com o teclado.

## 🚀 Tecnologias utilizadas

* 🐍 **Python**
* 🎮 **Pygame**
* 🖼️ Manipulação de imagens e gráficos
* 🔊 Áudio e efeitos sonoros
* ⌨️ Eventos e controles de teclado

## 📂 Estrutura do projeto

```text
python-pygameaula/
│
├── audio/          # Arquivos de áudio e efeitos sonoros
├── dist/           # Arquivos gerados para distribuição
├── font/           # Fontes utilizadas no projeto
├── graphics/       # Imagens e elementos gráficos
│
├── main.py         # Arquivo principal da aplicação
├── main.spec       # Configuração para geração do executável
└── README.md
```

## ⚙️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/DouglasTardioli/python-pygameaula.git
```

### 2. Entre na pasta

```bash
cd python-pygameaula
```

### 3. Instale o Pygame

```bash
pip install pygame
```

Ou:

```bash
python -m pip install pygame
```

### 4. Execute o projeto

```bash
python main.py
```

## 📚 Sobre o Pygame

O **Pygame** é uma biblioteca gratuita e open source para desenvolvimento de aplicações multimídia e jogos utilizando Python. Ela fornece recursos para trabalhar com gráficos, áudio, teclado, mouse, sprites e outros elementos necessários para jogos 2D.
